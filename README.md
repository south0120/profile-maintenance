# タレントプロフィール作成・メンテナンスツール（profile-maintenance）

タレント事務所において、Word / PowerPoint で手作業により行われているタレントの宣材プロフィール（コンポジット）作成を効率化し、
**「入力するだけで、事務所ブランドの整ったプロフィールが自動生成・更新できる」** 状態を目指すツールです。

**MVP v1 実装済み**（ブラウザで動くローカル版）。データはブラウザ内（IndexedDB）に保存され、ZIP バックアップで持ち出し・移行ができます。Google ドライブ同期・複数人利用は次フェーズ（StorageAdapter 抽象化済みのためアダプタ追加で対応）。

## 起動方法

```bash
npm install
npm run dev      # 開発サーバー → 表示されたURLをブラウザで開く
# 本番ビルドは npm run build → dist/ を任意の静的ホスティング(Vercel等)へ
```

※ Vercel 等に配置すれば、利用者は URL を開くだけで使えます（データは各自のブラウザ内に保存されます）。

## 使い方（5ステップ）

1. **設定** で事務所名・連絡先・ロゴを登録（全タレントのフッターに自動反映）
2. **タレント一覧 → ＋タレントを追加** で基本情報を入力
3. **写真タブ** に写真をドラッグ&ドロップ（用途: バストアップ/全身）。位置・拡大はスライダーで調整
4. **経歴タブ** で出演歴を入力（「強調」チェックで赤字太字）
5. **プレビュー → PDFに保存** で完成（印刷ダイアログで「PDFに保存」、余白: なし）

**経歴のストック運用とAI提案**: 経歴は削除せず全件ストックし、「表示」チェックで掲載を切り替えます。経歴タブの「営業先に合わせてAIが選抜・並べ替え」に営業先（例:「CM中心の広告代理店向け」）を書くと、AIが表示する経歴・並び順・強調（赤字）を提案します。内容を確認して反映→保存の二段階で、経歴の文面自体は変更されません。利用には設定画面で Anthropic APIキーの登録が必要です（従量課金）。

レイアウトを変えたいときは **レイアウト** タブへ。要素をドラッグで移動、角のハンドルでサイズ変更、右パネルで書式（フォント/サイズ/色/揃え）を調整して「テンプレートを保存」。変更は全タレントに反映されます。

**データの注意**: データは「同じPC・同じブラウザ」の中に保存されます。設定画面から定期的に**バックアップZIPを書き出し**、Googleドライブ等に保管してください（復元・PC移行も同画面から）。

## 解決したい課題（サマリ）

- プロフィールを Word / PowerPoint で 1 人ずつ手作業で作成しており時間がかかる
- 写真の差し替え、サイズ・経歴の更新のたびにレイアウトが崩れ、修正に手間がかかる
- 事務所ロゴ・サイン（署名）・連絡先などの共通要素が資料ごとにバラバラになりがち
- タレント数が増えるほど更新漏れ・版管理ミス（古いプロフィールの誤送付）のリスクが増える

## ゴール（サマリ）

- タレント情報（文字情報・写真）をローカル DB で一元管理し、テンプレートに流し込んで PDF を自動生成
- 写真の入れ替え・文字修正はフォーム操作のみ。レイアウトはテンプレートが保証
- **レイアウトはブラウザ上のエディタでドラッグ操作により自由に配置変更できる**（データとレイアウトは分離）
- 事務所ロゴ・サイン・カラーなどブランド要素はテンプレート側で一括管理・一括反映
- 更新履歴を保持し、常に「最新版」を確実に出力・共有できる

## 動作形態・規模（確定事項）

- **Windows / Mac 両対応。ブラウザだけで利用**（インストール不要）
- データ（タレント情報・写真・テンプレート）は**事務所の Google Workspace 共有ドライブ**に保存し、**複数人が同じデータを操作**（1 タレント＝1 ファイル＋版チェックで競合を防止）。将来の OneDrive 対応を見据えストレージ層は抽象化
- 所属タレント **50〜500 名** 規模を想定
- テンプレートは当面**営業用 1 種**（実物サンプル様式を再現）。会社ロゴ・マークはページ下部フッターに自動配置
- 出力様式の基準: 実物サンプル（A4 縦 1 枚、氏名＋基本情報＋写真 2 枚＋カテゴリ別経歴＋自己紹介＋動画リンク＋事務所フッター）
- **AI 支援**（第2フェーズ）: 自己紹介文の整形・校正、既存資料の貼り付けからの経歴自動構造化、Web からの最新活動情報の収集提案（すべて人の確認を経て保存）
